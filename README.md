# travel-agent
旅游攻略智能体

项目简介

本项目基于Trae平台纯SKILL.md实现，需额外Python脚本，无预设固定目的地，支持全球任意城市/景区自定义规划旅游行程。
智能提取用户出行全部个性化需求，结合官方文旅公开素材定制落地行程；合规渠道抓取景点实拍图并完成图文校验，最终自动生成报纸风格Markdown文字攻略+可视化HTML网页，解决通用旅游攻略同质化、无法贴合个人预算与喜好的痛点。
 
核心功能

1. 全参数自主提取：通过用户输入喜好或想、游玩天数、游玩人数、总预算、游玩偏好、饮食忌口。
2. 记忆联动适配：读取Memory历史出行习惯（住宿、交通、餐饮偏好）补全行程细节，无记忆则默认平价出行方案
3. 合规素材联网采集：通过Playwright调取地方文旅官网、维基共享资源，获取景点票价、开放时间、公交路线、平价食宿、避坑提示，拒绝商业反爬旅游平台
4. 个性化行程筛选：以用户喜好为核心筛选景点，严格控制总预算浮动≤5%，优先挑选优惠、公共交通，避开高消费项目，行程节奏宽松无高强度赶路
5. 景点图片自动抓取核验：每次全新下载实拍图，抓取一两张美食照片。景点照片命名统一为「景点名称.jpg」；校验图片与景点或美食的匹配度，图文不符则重新抓取，多次失败则文字备注不插入无关图片
6. 双格式自动导出：新建travel_output文件夹，同步生成报纸版式Markdown文档、可视化HTML网页，文末附上全部信息来源网页链接
 

内置MCP工具依赖

 - Memory：读取用户历史出行偏好记忆
- Fetch：辅助轻量化网页信息拉取
- File System：创建文件夹、写入MD/HTML成品文件
- Playwright：批量网页检索、景点图片下载
- Sequential thinking：多步骤链式推理，串联需求解析、素材抓取、行程生成、文件导出全流程
